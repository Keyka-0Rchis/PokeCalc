# テーブル定義書：ITEM（持ち物）

## カラム定義

| 列番号 | 物理名 | 論理名 | データ型 | キー | NULL | デフォルト値 | 備考 |
|---|---|---|---|---|---|---|---|
| 1 | item_id | 持ち物ID | int | PK | NO | | 持ち物の主キー識別用 |
| 2 | name | 名前 | text | | NO | | 持ち物の名前 |
| 3 | name_kana | なまえ | text | | NO | | 検索用ひらがな名 |

## 制約定義

| 制約名 | 制約種別 | 対象カラム | 定義・条件 | 備考 |
|---|---|---|---|---|
| pk_item | PRIMARY KEY | item_id | 一意、NOT NULL | 持ち物IDの一意性を保証 |

## 補足事項

- 持ち物を一意に識別するため、`item_id` を主キーとする。
- `name` は画面表示用の持ち物名を保持する。

# テーブル定義書：ABILITY（特性）

## カラム定義

| 列番号 | 物理名 | 論理名 | データ型 | キー | NULL | デフォルト値 | 備考 |
|---|---|---|---|---|---|---|---|
| 1 | ability_id | 特性ID | int | PK | NO | | 特性の主キー識別用 |
| 2 | name | 名前 | text | | NO | | 特性の名前 |
| 3 | name_kana | なまえ | text | | NO | | 検索用ひらがな名 |

## 制約定義

| 制約名 | 制約種別 | 対象カラム | 定義・条件 | 備考 |
|---|---|---|---|---|
| pk_ability | PRIMARY KEY | ability_id | 一意、NOT NULL | 特性IDの一意性を保証 |

## 補足事項

- 特性を一意に識別するため、`ability_id` を主キーとする。
- `name` は画面表示用の特性名を保持する。
- 特性の定義はマスタデータとして管理し、戦闘中の特性変更や無効化は計算処理側で扱う。
- 同名で異なる効果の特性「じんばいったい」が存在する（現状は区別の必要はないが）ため、名前にUNIQUE制約は付与しない。

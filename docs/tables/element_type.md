# テーブル定義書：ELEMENT_TYPE（タイプ一覧）

## カラム定義

| 列番号 | 物理名 | 論理名 | データ型 | キー | NULL | デフォルト値 | 備考 |
|---|---|---|---|---|---|---|---|
| 1 | type_id | タイプID | smallint | PK | NO | | タイプを識別するID |
| 2 | name | タイプ名 | text | | NO | | タイプ名。タイプなし（タイプを失った状態）はー扱い。 |

## 制約定義

| 制約名 | 制約種別 | 対象カラム | 定義・条件 | 備考 |
|---|---|---|---|---|
| pk_element_type | PRIMARY KEY | type_id | 一意、NOT NULL | タイプIDの一意性を保証 |
| uq_element_type_name | UNIQUE | name | 重複不可 | 同一タイプ名の重複登録を防止 |

## 補足事項

- `type_id` はタイプを一意に識別する固定IDとし、マスタデータで管理する。
- `name` はタイプの名称を保持する。同一名称の重複登録は認めない。
- タイプの追加・変更はマスタデータの更新によって行う。
